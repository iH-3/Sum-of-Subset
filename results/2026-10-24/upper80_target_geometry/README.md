# 本轮验证范围

`normal.json` 与 `optimized.json` 是九份**开放**记录的精确重放结果，逐字节一致。它们检查整数证书及其前提，不宣称任一原始根闭合。

`lemmas_normal.json` 与 `lemmas_optimized.json` 检查 23 个辅助模块，包含首个缺失值的三个完整有限最小化、完整四重和覆盖的实际集合对照，以及 23 项错误证书拒绝控制。实例对照不替代报告中的一般证明。

`regression_receipt.json` 记录此前秩切片、正洞切片和小松弛接口的普通/优化双模式回归；各对结果相同。`validation_receipt.json` 汇总本轮模式一致性、源文件清单及已有完整 81 包的源哈希核对。未将源哈希核对称为重新运行完整历史证明链。

`upper80_target_frontier_20261024.json.gz` 是另行保存的发现缓存，包含 176 个检查点、196 个共享前提，46 个检查点标为局部闭合。它不是完整分支覆盖证书，不计入任何新增根闭合。本轮仍有九个开放原始根，全局范围仍为 **71≤N≤81**。
