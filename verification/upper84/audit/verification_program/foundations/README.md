# Finite foundations of the consolidated upper-85 proof

This subtree supplies the finite mathematical checks needed by the accepted proof route. It is importable as `foundations`; the supported entry point is the parent `verify.py`, which calls `foundations.run_checks(mode='quick'|'full')`. Python 3.10 or later and the standard library suffice. No package installation, solver, network connection or original research directory is needed.

From the parent verification directory, run `python3 -I -S -B verify.py --full` for every finite stage, or `python3 -I -S -B verify.py --quick` for the explicitly partial fast check. On Windows use `py -3 -I -S -B verify.py --full` or the supplied batch launchers. The top-level runner writes `coverage.json` and `verification_log.txt`; `--output-dir` selects another output directory.

## Scope of a successful run

A full run reconstructs every finite object in the domains below and tests its actual mathematical inequalities. It does not accept stored `pass` fields as evidence. Fixed numerical inputs are the four sparse integer witnesses and the 160 synchronous proof traces; their inequalities are reconstructed and verified. Source hashes record identity, not mathematical validity.

A quick run completes the first six stages and reports the two larger finite bases as `SKIP`. It is not a complete finite-foundation validation.

1. **F3_NONAP_2340.** For every r=10,...,14 and q=1,2,3, enumerate every q-element deletion set below the retained maximum r+q. There are 2,340 sets, including 910 with positive subset-sum hole count. Exact subset sums and distinct-pair defects are computed with two independent representations; every positive-hole set satisfies rho >= r-5. `source/structural/foundations/nonap_defect.md` proves the signature/depth reduction to larger deleted intervals and the last-small-increment reduction to non-AP sets of size at least 21. Those universal written arguments are not replaced by the finite loop.
2. **F4_BOOTSTRAP_AP.** Recompute the SIZE86 constants, four small-size boundaries, and every k=0,...,20 AP/half-step scalar case. Twenty of the 21 rows require the detailed AP inequalities; the remaining row is excluded by its initial inequality. The nine surviving half-step relaxations are identified arithmetically.
3. **F4_INVERSE.** Recompute 17 inverse rows, four endpoint repairs, 13 dense-diameter rows, 30 oriented support-overlap alternatives and the two exceptional primitivity equalities. Applicability to actual sets and the lattice-forcing argument remain in the written STRUCTURAL86 proof.
4. **F4_FIXED_WITNESSES.** Reconstruct the semantic inequalities and expand all four exact positive-integer weighted sums over 72 nonprimitive, 72 relaxed half-step and eight size-14-boundary systems. Every resulting coefficient is nonnegative and every RHS is strictly negative. Minimum contradiction magnitudes are 283, 288 and 295 respectively. The nonnegative affine dependence of the half-step RHS on z is checked, so z=12 covers every 0<=z<=12. The redundant 256 even-z systems and the unstrengthened diagnostics are not run. The complete actual-set family proof is in `source/structural/ap_exception86/conditional_exception86.md`.
5. **F6_H_PROFILES.** Check only the needed thresholds h=15,17,21,49 and all r=15,...,54: 160 claims, 5,200 exhaustive AP/no-AP branches, 95,701 coordinate increases and 1,461,470 future-index checks. Every upper budget is computed from the OLD vector; mandatory initial AP costs, complete legal rounds, strict off-scale and bridge conditions and terminal contradictions are verified. Eleven corrupted-input controls and four strict-boundary control groups are rejected. These are supplied proof traces, not a search for better profiles.
6. **F6_H_BANDS.** Independently derive the four elementary paired floors 300,345,391,436 across all 40 physical orientations for each threshold. The finite band caps are 173,136,146; the unbounded tail is c+I+z<=151 for z>=49. They exclude all covering indices j>=3 and reduce H2 to 16 necessary scalar cells. The restricted direct-defect theorem gives the H2 contradiction with minimum margin 11. This four-band argument avoids the unnecessary historical 22,920-cell grid.
7. **F6_DENSE_BASES (full only).** Enumerate every bounded-density boundary set for beta=0,...,9: 227,239 cases. Also check all 1,728 admissible small sets of size 3,...,8. These lists overlap in 1,078 cases, so they contain 227,889 distinct sets in their union; they are not a disjoint partition. Exact bitset and independent set-valued subset-sum algorithms check the central interval and exact reflected endpoint holes. Written induction in `proof/dense_holes_direct_defects.tex`, with exact base/forward-difference arithmetic in the wrapper, extends the result to unbounded cardinality for beta<=9.
8. **F6_RESTRICTED_DIRECT (full only).** Enumerate all 43,758 eight-deletion and 48,620 nine-deletion patterns in 1,...,18, independently by combinations/bitsets and masks/Boolean DP. Exactly 151 and 1,108 pass the low-hole filter. Generate all three written deletion families at j=14,...,38: 91,875 complete sets, with 151j-251 at each size. Bitset and interval-union support algorithms and two distinct-pair defect methods agree. Every set has at least 15 holes and rho>=8j-44, with minimum margin zero at every size. The written inverse/tail/scale reduction yields the theorem for arbitrary primitive sets with 31<=r<=38 and h>=15: rho>=8r-112.

## Written proof boundary

The program is not a proof-assistant formalization. The covering and peeling arguments, actual-set row applicability, infinite signature and density reductions, endpoint propagation, rational integralization, accepted upper-86 starting theorem and cited published inverse/additive results remain mathematical arguments in the consolidated proof and the included retained source excerpts. In particular, a successful finite run alone is not an unconditional proof of N<=85.

`proof/endpoint_bridge_correction.txt` corrects the old bridge's interval endpoint to L-h-1 and allows integer adjacency. This is the correction used by the consolidated proof. The dense proof already uses the corrected endpoint form.

Some included source excerpts are historical reports and therefore describe the then-current global bound 71<=N<=86. They are retained only for the specific foundation theorems identified here; their historical status sections and old standalone replay instructions are not instructions for the consolidated package. The current theorem statement and composition are in the new consolidated proof.

## Implementation and optimization safety

The retained structural arithmetic routines use Python assertions. This wrapper deliberately compiles them with `optimize=0`, so their checks remain enabled even when the user runs Python with `-O`. A negative control rejects an impossible effective-hole witness in both modes. The wrapper and dense routines use explicit exceptions.

The structural exception module retains its exact row definitions and recombination function; its historical bulk runner was removed because it read redundant expected-output files and checked unneeded systems. Dense modules use package-relative imports; the profile module additionally removes the historical 280-claim bulk runner and restricts allowed thresholds to the four H thresholds, while retaining its inference and single-profile arithmetic unchanged. Certificate data contains precisely the four relevant hole thresholds. `SOURCE_MAP.json` records these transformations and both source and distributed hashes; `COVERAGE.json` maps every stage to its written proof dependency and mathematical scope.

No global descriptor census, endpoint-model reconstruction, LP optimization, Farkas search, profile discovery, or upper-bound search is included.
